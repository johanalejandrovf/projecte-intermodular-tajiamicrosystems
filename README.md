# Tajia Microsystems S.L.

## Presentación del proyecto
Nuestra proyecto consiste en la implementación de una infraestructura informática completa, cumpliendo los más estrictos estándares de seguridad. Con un uso fiable y eficáz tanto dentro de la empresa como fuera de ella, proporcionando sus servicios a clientes a través de Internet.
