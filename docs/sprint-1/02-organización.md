# Departamentos y estructura organizativa

## Departamentos principales

Tajia Microsystems S.L. tiene 25 trabajadores repartidos en una dirección y cuatro departamentos: Gestión, Implantación, Taller y Desarrollo web.

| Departamento | Nº de trabajadores |
|--------------|--------------------|
| Dirección General | 2 |
| Gestión | 4 |
| Implantación | 9 |
| Taller | 6 |
| Desarrollo web | 4 |
| **Total** | **25** |

## Funciones y responsabilidades de cada departamento

- **Dirección General:** decide la estrategia de la empresa, coordina a todos los departamentos y se encarga de las relaciones con los clientes grandes y los proveedores.
- **Gestión:** lleva la administración, la contabilidad, los pedidos y las facturas. También organiza las citas con los clientes y les atiende, dando prioridad a las instalaciones más grandes.
- **Implantación:** instala en casa del cliente el cableado físico y de red (cables, tomas, armarios de comunicaciones y equipos de red) y comprueba que todo funciona.
- **Taller:** prepara y configura los servidores y los sistemas operativos antes de la instalación, repara equipos y se encarga del mantenimiento y la seguridad de los sistemas.
- **Desarrollo web:** crea y mantiene las páginas web y los servicios online que la empresa ofrece a sus clientes a través de Internet.

## Puestos de trabajo y funciones principales

| Departamento | Puesto | Funciones principales |
|--------------|--------|-----------------------|
| Dirección | Director/a general (1) | Dirigir la empresa y tomar las decisiones importantes |
| Dirección | Director/a técnico y de calidad (1) | Coordinar Implantación, Taller y Desarrollo web y vigilar la calidad y la seguridad |
| Gestión | Responsable de administración (1) | Contabilidad, facturas y pagos |
| Gestión | Comercial y atención al cliente (2) | Atender a los clientes, dar presupuestos y gestionar las citas |
| Gestión | Auxiliar administrativo (1) | Pedidos, compras y papeleo |
| Implantación | Jefe/a de equipo (1) | Organizar las instalaciones y repartir el trabajo |
| Implantación | Técnico/a de cableado y redes (8) | Tender cableado, montar tomas y armarios y configurar equipos de red |
| Taller | Administrador/a de sistemas (2) | Configurar servidores y sistemas operativos |
| Taller | Técnico/a de soporte (3) | Reparar equipos y atender incidencias |
| Taller | Técnico/a de seguridad (1) | Proteger los sistemas y revisar las copias de seguridad |
| Desarrollo web | Jefe/a de proyecto (1) | Planificar los proyectos web y hablar con el cliente |
| Desarrollo web | Desarrollador/a web (2) | Programar y mantener las webs y los servicios online |
| Desarrollo web | Diseñador/a web (1) | Diseñar el aspecto de las páginas |
